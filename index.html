Biomedical Embedded SYS_ID: STM32-AF-01

PPG-Based Atrial Fibrillation (AF) Detection on STM32 — Inter-Patient Validation

Developing an edge-based cardiac arrhythmia detection system on ARM Cortex-M (STM32). Acquires Photoplethysmogram (PPG) optical signals, removes motion artifacts through digital bandpass filtering, extracts HR/HRV time-domain features, and executes lightweight classification with patient-disjoint validation for unseen subjects.

Firmware Pipeline Architecture
PPG Optical Sensor → STM32 ADC (DMA) → 0.5-5Hz Bandpass → HR/HRV Analysis → AF Inference
